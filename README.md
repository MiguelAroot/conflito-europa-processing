# Europa em disputa

Jogo de estratégia territorial em Processing 4, no modo Java. O mapa tem 30 países, 60 regiões e 76 ligações.

1. Baixe e extraia o repositório inteiro.
2. Abra [`EuropaEmDisputa/EuropaEmDisputa.pde`](EuropaEmDisputa/EuropaEmDisputa.pde) no Processing 4.
3. Clique em **Run**. Use **F11** para alternar a tela cheia.
